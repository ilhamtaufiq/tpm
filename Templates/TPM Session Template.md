**Cara pakai template ini di Obsidian:**
1. Install plugin **Templates** (built-in, tinggal aktifkan) atau **Templater** (community plugin, lebih fleksibel).
2. Set folder template ke `Templates/`.
3. Bikin file baru di `Sessions/` dengan nama `YYYY-MM-DD HHmm - Topik.md`, lalu jalankan perintah "Insert template" → pilih file ini.
4. Isi frontmatter di atas (date, time, module, status, agent, files) — ini kunci pencarian, jangan dikosongi.
5. Hapus blok "Cara pakai template ini" ini setelah insert (baris ini cuma instruksi, bukan bagian isi sesi).
