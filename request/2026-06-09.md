# Perubahan Hari Ini - 2026-06-09

Dokumentasi ringkas perubahan yang dikerjakan hari ini di repo `tpm`.

## Ringkasan

- Menyamakan label menu agar nama yang tampil konsisten di seluruh frontend.
- Merapikan navigasi wallet supaya tombol kembali mengikuti urutan halaman.
- Mengganti icon menu `Bengkel` dan `Service` agar tidak sama.
- Menampilkan semua sparepart saat restock.
- Menambahkan dukungan DP / Bayar Awal di transaksi bengkel.
- Menambahkan opsi tampilkan / sembunyikan diskon pada semua cetak struk yang relevan.
- Memindahkan toggle mode mobile / desktop agar tidak menutup tombol home.
- Menyederhanakan `BengkelForm` jadi satu pintu untuk pilih sparepart dan servis.
- Menambahkan dukungan print web via QZ Tray dengan fallback ke print dialog browser.
